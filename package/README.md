# Dope Icons

242 icons, each in 3 styles, 4 corner sets and 3 stroke weights. Drawn on a 24px grid. Every icon is split into named parts, so you can animate them.

- **Styles:** `outline`, `solid`, `duotone`
- **Corners:** `sharp` (0), `subtle` (1.25), `round` (2.5, default), `soft` (4)
- **Weights:** `light` (1px), `regular` (1.5px, default), `bold` (2px). Every style follows the weight, solid included.
- **Color:** every file uses `currentColor`, so icons follow your text color in light and dark themes.

## React

```jsx
import { IconHome, IconSend } from "dope-icons";

<IconHome />
<IconSend variant="solid" corner="soft" size={32} />
<IconHome variant="duotone" weight="bold" color="#b8ff33" title="Home" />
```

| Prop | Values | Default |
| --- | --- | --- |
| `variant` | `outline` · `solid` · `duotone` | `outline` |
| `corner` | `sharp` · `subtle` · `round` · `soft` | `round` |
| `weight` | `light` · `regular` · `bold` | `regular` |
| `size` | number or CSS size | `24` |
| `color` | any CSS color | `currentColor` |
| `strokeWidth` | number, overrides `weight` | — |
| `title` | text for screen readers; without it the icon is hidden from them | — |

## SVG files

`svg/{weight}/{corner}/{style}/{name}.svg`, e.g. `svg/regular/round/outline/home.svg`.

## Sprites

`sprite/{corner}-{style}.svg` holds one `<symbol id="dope-{name}">` per icon (regular weight).

```html
<svg width="24" height="24"><use href="sprite/round-outline.svg#dope-home" /></svg>
```

## Other platforms

`json/dope-icons.json` has the raw path data for every icon, style and corner set. Use it to generate assets for iOS, Android, Flutter or Figma.

## Animation

Each part is a `<g data-part="…">`. React adds the classes `dope-part dope-part-{name}`.

```css
.dope-icon:hover .dope-part-head { transform: translateX(2px); transition: transform .2s; }
```

## Rebuild

This package is generated by Dope Icons Studio (`npm run build` in the studio repo).
